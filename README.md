# Riddhi Consultant — One Page Website

Static website for Riddhi Consultant, Indore.

## Files
- `index.html` — website
- `style.css` — design/responsive styling
- `script.js` — product data, mobile menu and quote enquiry mailto

## Before publishing
1. Replace `+91 8XXXXXXXXX7` in `index.html` and `script.js` with the actual WhatsApp/phone number.
2. If you have a logo, replace the text "R" mark with your logo.
3. Review the product names and company copy.

## GitHub Pages
Create a GitHub repository, upload these three files to the root, then:
Settings → Pages → Deploy from branch → main → / (root).

## Cloudflare
You can either use Cloudflare Pages with the GitHub repository or keep GitHub Pages as the origin and manage the custom domain/DNS through Cloudflare.
